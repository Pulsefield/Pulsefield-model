## Direction and authority

The user selects a35M teacher followed by distillation. The active goal separately
authorizes model changes and bounded execution. Keep this Note proposed, with no
Card acceptance implied. The existing response6.75M remains the quality baseline;
no output or inherited checkpoint is replaced. Only the engineering preflight is
selected here, not an unbounded pretraining run or student distillation.

Closest analogue for the later phase is Hinton et al.'s soft-distribution knowledge
distillation (https://arxiv.org/abs/1503.02531), with student-native prefix coverage
motivated by on-policy sequence distillation (https://arxiv.org/abs/2306.13649).
Those mechanisms transfer; quality and capacity requirements must be measured in
this exact timed-row task. Source-bounded novelty assessment: task adaptation,
not a proposed new distillation algorithm. The present preflight changes only
width and execution size and makes no learning-novelty claim.

## Pretraining and distillation handoff

The35M teacher is feasible at the tested shapes on this Mac, so it remains the
selected main scale. A first30M-onset target with44h hard wall budget is a useful
planning bound; extrapolating this pilot alone gives about32.6h before checkpoint
and validation overhead, but must not be presented as a completion guarantee.
The corpus includes shapes and longer histories not covered by these four crops.

Before starting the unattended worker, add an explicit teacher-sized bounded
training/generation profile and its tests, accommodate the observed422MB Adam
checkpoint with a declared byte limit, freeze its full source plan and fixed
validation cadence, and verify ordinary durable runner recovery at that profile.
Do not bypass the current128-hidden/checkpoint-size limits and call that a normal
supported long run. Existing small-model defaults and original dirty worktree
remain untouched. Then freeze the long-run Card and queue budget; none is running
as of this Result Log.

Treat35M as the choreography network only. A later frozen music encoder is a
separate parameter/latency cost. Distilling35M to9.38M does not automatically
compress that audio encoder or give an audio-free student audio-conditioned
ability. Prioritize strong teacher/native validation and reusable audio caches
before student compression; perform any final compression after the desired
conditioning path is stable. Keep source CE beside distribution matching, query
the teacher on student-native histories, and recheck long-form organization,
difficulty burden and independent LN/TAP at the student scale. A weak teacher
must not become a mandatory source of pseudo-ground-truth.
